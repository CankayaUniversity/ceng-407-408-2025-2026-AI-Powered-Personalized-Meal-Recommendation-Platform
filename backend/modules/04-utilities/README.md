<a name="english"></a>
## English

Utility tools used throughout the application and development conveniences are located in this module.

### 📦 Responsibilities
- **Data Populator:** Fills the database with test data when the application starts.
- **Common Helpers:** General helper classes shared between modules.

### 📂 Key Components
- `datapopulator/`: Test data loading services.

### 🔗 Dependencies
Usually works dependent on **Domain** models.
